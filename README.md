# Предпросмотр независимой админки

Это статический безопасный предпросмотр будущего интерфейса владельца магазина.

- Не загружает Telegram SDK.
- Не выполняет вход и не обращается к API или базе данных.
- Не показывает товары, заказы, цены, остатки или персональные данные.
- Кнопка «Посмотреть интерфейс» открывает только макет главного экрана с пустыми значениями.

Файлы входа и реальной работы с данными будут добавляться отдельными этапами после проверки HTTPS и серверной авторизации.
